# The AI Prompt Suite (when to use each)

Source: *The Starter Dose* (ClickDose): twelve prompts, in the order ClickDose uses them. The kit's full prompt texts are behind "Copy" buttons and weren't in the exported PDF. If the user has them, ask them to paste the text into this file. Until then, run each step as a task with the purpose below. The model is only as good as the inputs: ask for real reviews, ads and product facts.

## Research (01–03)

| # | Prompt | Use when |
|---|---|---|
| 01 | **The Ad Teardown** | A competitor ad is clearly working (running 60+ days) and you want the machine, not the words: hook, belief it installs, mechanism, proof, offer, CTA. |
| 02 | **The Kitchen-Table Nickname** | The category describes the problem in clinical or technical language; find the phrase customers would say at the kitchen table. |
| 03 | **The Review Miner** | Before writing anything. Customers already wrote the copy: pull their exact phrases for pains, desires, objections, outcomes. |

## Write (04–06)

| # | Prompt | Use when |
|---|---|---|
| 04 | **The Dialogue Caption Writer** | Writing an advertorial-in-caption ad where an authority figure does the selling. |
| 05 | **The Framework Transplant** | You tore down a winning ad (01) and want its machine rebuilt for this brand and category. |
| 06 | **The Page Drafter** | Drafting any of the 7 page formats: paste the blueprint anatomy from `blueprints.md`; fill the skeleton section by section. |

## Strengthen (07–11)

| # | Prompt | Use when |
|---|---|---|
| 07 | **The Headline Stack** | A drafted page has a placeholder headline. Never test one headline: write 10+, grouped by angle, pick 2–3 to test. |
| 08 | **The Objection Autopsy** | Turn real objections into FAQ, guarantee copy and mid-page interruptions, not an FAQ answering questions nobody asked. |
| 09 | **The Offer Stack Builder** | Structuring tiers, guarantee and price framing for the offer section. |
| 10 | **The Message-Match Rewrite** | Ad and page were written on different days in different moods, and the click can feel it. Rewrite the first screen to continue the ad. |
| 11 | **The Before/After Story** | Writing proof sections that read like humans, not stock photos with captions. Real stories only. |

## Attack (12)

| # | Prompt | Use when |
|---|---|---|
| 12 | **The Page Grader** | The draft is "done." Attack it before traffic does: run the 10-check audit, then list the three biggest leaks with fixes. |
